# RLHF pipeline: SFT, reward models and PPO

A compact DistilGPT-2 alignment experiment covering supervised fine-tuning, synthetic preference generation, pairwise reward modeling and custom sequence-level PPO with KL regularization.

## Running the inspected V2 workflow

Install `requirements.txt`, review `config.py`, then run these scripts from the repository root:

```text
python step1_generate_preference_data.py
python step0_sft.py
python step2_train_reward_model.py
python step3_ppo_v2.py
python step5_compare.py
```

`step3_ppo_training.py` and `step4_analysis.py` retain the earlier baseline workflow. `run_pipeline.py` is the legacy V1 runner and does not automatically include SFT or PPO V2. Preference examples are generated by the included script; training artifacts are created under `data/` and `outputs/`.

Technologies: Python, PyTorch, Transformers, NumPy and Matplotlib. Evaluation scripts inspect reward behavior, out-of-distribution behavior and potential reward hacking. This is a research/learning project, distinct from the related course RL_Challenge_2 repository. No validated alignment improvement or production-scale capability is claimed.

Generated datasets, checkpoints, reports and model outputs are not bundled. Source syntax was checked, but training was not rerun during publication. Dependencies are not a locked reproduction environment; review hardware and package compatibility before a full run.
